# math

## `builtin_math`

Built-in math functions and constants

**Examples:**
```awkward
math.sin(x)  # returns the sine of x
math.cos(x)  # returns the cosine of x
math.floor(2.7)   # 2
math.ceil(2.1)    # 3
math.round(2.5)   # 3
math.min(3, 7)    # 3
math.max(3, 7)    # 7
math.random()     # a float in [0, 1)
math.PI           # 3.14159...
math.E            # 2.71828...
```
